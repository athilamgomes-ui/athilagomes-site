# athilagomes.com.br

Site dos cursos de Áthila Gomes. Página do **Investindo com Sabedoria** — turma presencial
de 17/10/2026, em Altamira/PA.

- `index.html` — a página. Toda configuração fica no bloco `CONFIG`, no fim do arquivo.
- `RUNBOOK_CURSOS.md` — estratégia, cronograma, decisões e armadilhas. **Leia antes de mexer.**
- `lancamento_whatsapp.md` — sequência de mensagens do lançamento.
- `supabase_schema.sql` — tabela de leads (roda uma vez).

⚠️ Não abrir o `index.html` no TextEdit: converte para RTF e destrói o arquivo.
